## 二、问题1建模思路（核心）

### 1. 模型设定
- 设零配件次品率为 $p$，标称值 $p_0 = 10\%$
- 抽样 $n$ 件，检出次品数 $X \sim B(n, p)$
- 企业需在**最少样本量**下做出接收/拒收决策

### 2. 两种情形的检验框架

**情形(1)：95%信度下认定次品率超过标称值则拒收**
- 原假设 $H_0: p \le p_0$（合格），备择假设 $H_1: p > p_0$（不合格）
- 需找到最小 $n$ 和临界值 $c$，使得：
  - 当 $p = p_0$ 时，$P(X > c) \le 5\%$（控制第一类错误，即误拒概率 ≤ 5%）
  - 即：$P(X \le c) \ge 95\%$ 在 $p=p_0$ 下成立
- 实际做法：**给定 $n$，找最小 $c$ 使 $P_{p_0}(X \le c) \ge 0.95$**，然后逐步增大 $n$ 直到满足拒收的判别条件

**情形(2)：90%信度下认定次品率不超过标称值则接收**
- 原假设 $H_0: p \ge p_0$（不合格），备择假设 $H_1: p < p_0$（合格）
- 需找到最小 $n$ 和临界值 $c$，使得：
  - 当 $p = p_0$ 时，$P(X < c) \le 10\%$（控制误收概率 ≤ 10%）
  - 即：$P(X \ge c) \ge 90\%$ 在 $p=p_0$ 下成立

### 3. 具体数值计算方案（给编程手）

```python
# 情形(1)：95%信度拒收
# 对 n 从 1 开始递增：
#   找最小 c 使得 P(X<=c | p=0.1) >= 0.95
#   若 c/n < 0.1（即样本次品率低于标称），则此 n 满足要求
#   取第一个满足条件的 n

# 情形(2)：90%信度接收
# 对 n 从 1 开始递增：
#   找最小 c 使得 P(X>=c | p=0.1) >= 0.90
#   若 c/n > 0.1，则此 n 满足要求
#   取第一个满足条件的 n
```

**预期结果**（我预估）：
- 情形(1)：$n \approx 29$（因为 $P(X \le 1|p=0.1, n=29) \approx 0.95$ 附近）
- 情形(2)：$n \approx 22$（因为 $P(X \ge 3|p=0.1, n=22) \approx 0.90$ 附近）

## 三、问题2建模思路（核心）

### 1. 决策变量

对每个零配件 $i$：是否检测 $d_i \in \{0,1\}$
对成品：是否检测 $d_f \in \{0,1\}$
对不合格成品：是否拆解 $d_r \in \{0,1\}$

### 2. 期望成本模型

设：
- $p_i$：零配件 $i$ 次品率，$c_i$：购买单价，$t_i$：检测成本
- $p_f$：成品次品率（正品配件装配后），$c_a$：装配成本，$t_f$：成品检测成本
- $s$：市场售价，$L$：调换损失，$r$：拆解费用

**关键推导**：

**（a）零配件检测决策**：
- 不检测时，每个配件期望成本 = $c_i$（次品也进入装配）
- 检测时，每个配件期望成本 = $c_i + t_i$（检测后丢弃次品，但需购买正品替代）
- 检测的净收益：检测能避免次品进入后续环节带来的损失

**（b）成品检测决策**：
- 不检测成品：所有成品进入市场，不合格品造成调换损失
- 检测成品：检测合格的进入市场，不合格的进入拆解/报废决策

**（c）拆解决策**：
- 报废：损失 = 已投入成本（配件+装配+检测）
- 拆解：花费拆解费 $r$，回收零配件（正品可重新利用）

### 3. 决策树/期望成本最小化

对每种情形，枚举 $2^3 = 8$ 种决策组合，计算总期望成本，取最小者。

**单位产品期望成本公式**（以1件成品为基准）：

设 $q_i$ 为进入装配的零配件 $i$ 的次品率：
- 若检测：$q_i = 0$（次品被丢弃，但需多买配件）
- 若不检测：$q_i = p_i$

成品次品率（考虑配件次品）：
$$P_{bad} = 1 - (1-q_1)(1-q_2)(1-p_f)$$

**期望成本 = 配件成本 + 检测成本 + 装配成本 + 成品检测成本 + 市场相关成本**

### 4. 给编程手的计算框架

```python
        for 配件2检测? in [0,1]:
            for 成品检测? in [0,1]:
                for 不合格品拆解? in [0,1]:
                    计算单位产品期望成本
    输出最优决策组合及对应成本
```

## 四、问题3建模思路

### 1. 结构分析
- 2道工序、8个零配件
- 工序1：配件1-4 → 半成品1；配件5-8 → 半成品2（根据表2推断）
- 工序2：半成品1、2 → 成品

### 2. 方法
- **动态规划**：从后往前递推
- 每个节点（配件/半成品/成品）有检测/不检测两个选择
- 状态转移：考虑检测成本 vs 不合格品流入下游的期望损失

### 3. 递推公式

对节点 $j$，设 $V_j$ 为从该节点开始的最小期望成本：
$$V_j = \min\{ \text{不检测成本}, \text{检测成本} \}$$

其中检测成本 = 检测费 + 正品继续加工成本，不检测成本 = 次品率 × 下游损失 + 正品率 × 下游成本。

from scipy.stats import binom

def find_min_n_case1(p0=0.10, confidence=0.95):
    """
    情形(1)：在95%信度下认定次品率超过标称值则拒收
    即：当 p = p0 时，P(X > c) <= 5%，即 P(X <= c) >= 95%
    需要找到最小 n 和临界值 c，使得：
    - P(X <= c | p=p0) >= 0.95
    - 且 c/n < p0（样本次品率低于标称值，才能做出"超过标称值"的判断）
    
    实际上更准确的理解：
    我们需要找到一个抽样方案(n, c)，使得：
    如果样本中次品数 > c，则拒收（认为次品率超过标称值）
    在 p = p0 时，误拒概率 <= 5%，即 P(X > c | p=p0) <= 0.05
    即 P(X <= c | p=p0) >= 0.95
    
    同时，为了能做出"拒收"决策，需要存在某个样本结果使得 X > c
    即 c < n（至少存在一个样本结果能触发拒收）
    
    但更关键的是：我们需要保证在 p = p0 时，P(X > c) <= 0.05
    同时希望 n 尽可能小。
    
    实际上，标准做法是：
    对每个 n，找最小的 c 使得 P(X <= c | p=p0) >= 0.95
    然后检查这个方案是否合理（c < n）
    取最小的 n。
    """
    n = 1
    while True:
        # 找最小的 c 使得 P(X <= c) >= 0.95
        c = 0
        while True:
            prob = binom.cdf(c, n, p0)
            if prob >= confidence:
                break
            c += 1
            if c > n:
                break
        if c < n:  # 存在拒收的可能
            # 验证：在 p=p0 时，误拒概率 = P(X > c) = 1 - P(X <= c) <= 0.05
            prob_accept = binom.cdf(c, n, p0)
            prob_reject = 1 - prob_accept
            if prob_reject <= (1 - confidence) + 1e-10:
                return n, c, prob_accept, prob_reject
        n += 1
        if n > 10000:
            break
    return None

def find_min_n_case2(p0=0.10, confidence=0.90):
    """
    情形(2)：在90%信度下认定次品率不超过标称值则接收
    即：当 p = p0 时，P(X < c) <= 10%，即 P(X >= c) >= 90%
    需要找到最小 n 和临界值 c，使得：
    - P(X >= c | p=p0) >= 0.90
    - 且 c/n > p0（样本次品率高于标称值，才能做出"不超过标称值"的判断）
    
    更准确的理解：
    我们需要找到一个抽样方案(n, c)，使得：
    如果样本中次品数 < c，则接收（认为次品率不超过标称值）
    在 p = p0 时，误收概率 <= 10%，即 P(X < c | p=p0) <= 0.10
    即 P(X >= c | p=p0) >= 0.90
    
    同时，为了能做出"接收"决策，需要存在某个样本结果使得 X < c
    即 c > 0（至少存在一个样本结果能触发接收）
    """
    n = 1
    while True:
        # 找最小的 c 使得 P(X >= c) >= 0.90
        # 即 P(X < c) <= 0.10
        c = 0
        while True:
            prob_less = binom.cdf(c-1, n, p0)  # P(X < c) = P(X <= c-1)
            if prob_less <= (1 - confidence) + 1e-10:
                break
            c += 1
            if c > n + 1:
                break
        if c > 0 and c <= n:  # 存在接收的可能
            prob_accept = 1 - binom.cdf(c-1, n, p0)  # P(X >= c)
            prob_error = binom.cdf(c-1, n, p0)  # P(X < c) = 误收概率
            if prob_error <= (1 - confidence) + 1e-10:
                return n, c, prob_accept, prob_error
        n += 1
        if n > 10000:
            break
    return None

## 一、问题1建模思路存在根本性错误

### ❌ 建模手的错误理解

建模手将问题1理解为"**假设检验**"框架，试图寻找最小样本量使得在标称值 $p_0=10\%$ 下控制误判概率。但**赛题的实际含义完全不同**：

> **赛题原文**："在95%的信度下认定零配件次品率**超过标称值**，则拒收这批零配件"

这句话的意思是：**企业需要设计一个抽样方案，使得当实际次品率确实超过标称值时，企业有95%的把握（信度）能发现并拒收**。

### ✅ 正确的建模框架

设抽样 $n$ 件，检出次品数 $X \sim B(n,p)$，临界值为 $c$（$X > c$ 则拒收）。

**情形(1)**：在95%信度下认定次品率超过标称值则拒收
- 含义：当实际次品率 $p > p_0$ 时，拒收概率 $\ge 95\%$
- 即：$P(X > c \mid p = p_0) \ge 95\%$（在最接近标称值的超标情形下也要有95%把握）
- 等价于：$P(X \le c \mid p = p_0) \le 5\%$

**情形(2)**：在90%信度下认定次品率不超过标称值则接收
- 含义：当实际次品率 $p \le p_0$ 时，接收概率 $\ge 90\%$
- 即：$P(X \le c \mid p = p_0) \ge 90\%$（在最接近标称值的达标情形下也要有90%把握）
- 等价于：$P(X > c \mid p = p_0) \le 10\%$

### 🔑 关键区别

| | 建模手的理解（错误） | 正确理解 |
|:---|:---|:---|
| 情形(1) | 在 $p=p_0$ 时误拒概率 ≤ 5% | 在 $p=p_0$ 时拒收概率 ≥ 95% |
| 情形(2) | 在 $p=p_0$ 时误收概率 ≤ 10% | 在 $p=p_0$ 时接收概率 ≥ 90% |

**建模手把"信度"理解反了！** 信度是指"认定"的把握程度，而不是"误判"的概率上限。

### 二、决策变量

- 成品是否检测 $d_f\in\{0,1\}$

### 三、关键概率推导

**进入装配的配件 $i$ 的次品率 $q_i$：**
$$q_i = \begin{cases}0 & d_i=1 \text{（检测后丢弃次品）}\\ p_i & d_i=0 \text{（不检测）}\end{cases}$$

**成品出厂时的次品率（装配后未检测）**：
$$P_{bad} = 1 - (1-q_1)(1-q_2)(1-p_f)$$

### 四、单位产品期望成本公式（以生产1件成品为基准）

**① 配件成本（含检测）**
$$\text{配件总成本} = \sum_i \big[ c_i + d_i\, t_i + (1-d_i)\cdot 0 + d_i\, \text{(次品替代成本)}\big]$$

需要细分：检测时，$q_i=0$ 但需购买 $1/(1-p_i)$ 件配件才能得到1件合格件（次品被丢弃）。设 $m_i$ 为生产1件成品需消耗的配件 $i$ 数量期望：
$$m_i = \frac{1}{(1-p_i)^{d_i}} \quad\text{（检测时 $m_i=1/(1-p_i)$，不检测时 $m_i=1$）}$$

配件环节总成本 $C_{parts} = \sum_i m_i(c_i + d_i\, t_i)$

**② 装配成本**
$$C_{assemble} = c_a \cdot N_{成品}$$

**③ 成品检测成本**
$$C_{finish\_det} = d_f \cdot t_f$$

**④ 不合格成品处置（拆解/报废）**
- 若 $d_f=0$（成品不检测）：所有成品流向市场，其中次品率 $P_{bad}$ 触发调换损失 $L$：
  $$C_{market} = P_{bad}\cdot L$$
- 若 $d_f=1$（成品检测）：检测出不合格品，其比例 $P_{bad}$，对其进行拆解或报废：
  - **报废**：损失已投入成本 $C_{parts}+C_{assemble}$
  - **拆解**：花费拆解费 $r$，可回收合格配件（减少后续配件采购）
  $$C_{bad\_dispose} = P_{bad} \cdot \begin{cases} C_{parts}+C_{assemble} & \text{报废}\\ r + \text{可回收价值} & \text{拆解}\end{cases}$$

其中：
- 若拆解后检测（$d_i'=1$）：花费检测费 $t_i$，合格件可重新利用

## ✅ 二、问题2 完整期望成本模型（关键公式）

### 核心量
| 量 | 公式 |
|:---|:---|
| 供给1件合格配件i成本（检测） | $P_i=\dfrac{c_i+t_i}{1-p_i}$ |
| 供给1件合格配件i成本（不检测） | $P_i=c_i$ |
| 装配后成品合格率 | $P_{good}=g_1g_2(1-p_f)$，其中 $g_i=1$（检测）或 $1-p_i$（不检测） |
| 成品不合格率 | $P_{bad}=1-P_{good}$ |

### 全生命周期期望成本（固定点递推，已纳入**拆解后二次检测**）
$$X = \underbrace{(P_1+P_2+c_a+t_f\cdot d_f)}_{\text{首件装配成本}} + P_{bad}\cdot\text{缺陷处理成本} - P_{good}\cdot s$$

**缺陷处理成本**（关键，含指导老师要求的拆解后二次检测）：
- 流入市场被退回（$d_f=0$）：$+L$
- 拆解（$d_r=1$）：$+r$，回收配件按 $d_1',d_2'$ **重新检测**，回收件质量取决于首件是否检测：
  - 首件检测过（$d_i=1$）→ 回收件必合格
  - 首件未检测（$d_i=0$）→ 回收件合格概率 $=1-p_i$
  - 重新检测 $d_i'=1$ 时，回收不合格件可丢弃换新
- 报废（$d_r=0$）→ 重做一件全新件（$+X$）

> 🔧 **求解方法**：$X$ 与 $X_{rec}$（用回收件时的成本）互相依赖，用**固定点迭代**求解。枚举 $(d_1,d_2,d_f,d_r,d_1',d_2')$ 共 $2^6=64$ 种组合，取期望净成本最小者为最优。

"""

# ============ 数据定义 ============
# 配件: (次品率, 购买单价, 检测成本)
parts = {

    2: (0.10, 8, 1),

def part_cost(part_id, inspect):
    """配件供给1件合格件的期望成本"""
    p, c, t = parts[part_id]
    if inspect:
        return (c + t) / (1 - p), 1.0   # 检测后必合格
    else:
        return c, 1 - p                 # 不检测，合格概率 1-p


def node_cost(children, p_node, ca, t_node, r_node, is_final=False):
    """
    计算一个节点（半成品或成品）的最小期望成本
    children: 子节点列表，每个元素为 (子节点供给成本, 子节点合格概率)
    p_node: 本节点装配后的次品率（子件都合格时仍可能不合格）
    ca: 装配成本
    t_node: 本节点检测成本
    r_node: 拆解费（若为None表示不可拆解）
    is_final: 是否为成品（成品有市场售价和调换损失）
    """
    best_cost = float('inf')
    best_decision = None

    for inspect in (0, 1):
        for dismantle in (0, 1):
            if dismantle and r_node is None:
                continue  # 不可拆解

            # 子件供给成本（子件已是最优决策后的成本）
            child_cost = sum(c for c, _ in children)
            # 子件全部合格的概率
            child_good = 1.0
            for _, g in children:
                child_good *= g

            # 本节点装配后合格概率
            P_good = child_good * (1 - p_node)
            P_bad = 1 - P_good

            # 基础成本：子件成本 + 装配 + 检测
            base = child_cost + ca + (t_node if inspect else 0)

            if is_final:
                # 成品：有市场收益和调换损失
                L_m = L if not inspect else 0  # 不检测则不合格品流入市场被退回
                if dismantle:
                    # 拆解：回收子件，重新装配（简化：回收子件按原最优决策重新供给）
                    # 拆解后子件重新供给成本 = 子件原成本（因为子件已是最优）
                    # 但拆解后子件质量取决于原检测情况，这里用近似：拆解后重新走子件最优决策
                    rec_child_cost = child_cost  # 近似：回收子件重新按最优决策处理
                    rec_base = rec_child_cost + ca + (t_node if inspect else 0)
                    # 拆解后重新装配的合格概率（子件重新供给后）
                    rec_P_good = child_good * (1 - p_node)
                    rec_P_bad = 1 - rec_P_good
                    # 拆解后继续加工的成本（固定点）
                    X_rec = (rec_base + r_node - rec_P_good * s + rec_P_bad * L_m) / rec_P_good
                    X = base - P_good * s + P_bad * L_m + P_bad * X_rec
                else:
                    # 报废：失败即重做
                    X = (base - P_good * s + P_bad * L_m) / P_good
            else:
                # 半成品：无市场收益，只计算到本节点的成本
                if dismantle:
                    # 拆解：回收子件重新装配
                    rec_child_cost = child_cost
                    rec_base = rec_child_cost + ca + (t_node if inspect else 0) + r_node
                    rec_P_good = child_good * (1 - p_node)
                    rec_P_bad = 1 - rec_P_good
                    # 半成品拆解后重新装配，直到合格
                    X = (base + P_bad * (rec_base / rec_P_good)) / P_good
                else:
                    # 报废：失败即重做
                    X = base / P_good

            if X < best_cost:
                best_cost = X
                best_decision = (inspect, dismantle)

    return best_cost, best_decision
