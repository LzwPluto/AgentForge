## 二、问题2 完整期望成本模型（含拆解后二次检测）

### 2.1 决策变量
- 配件 i 是否检测：d_i ∈ {0,1}，i=1,2
- 成品是否检测：d_f ∈ {0,1}
- 不合格成品是否拆解：d_r ∈ {0,1}
- 拆解后配件 i 是否重新检测：d_i' ∈ {0,1}（重复步骤1）

### 2.2 参数
- p_i, c_i, t_i：配件i次品率、单价、检测费
- p_f, c_a, t_f：成品次品率、装配费、成品检测费
- s, L, r：售价、调换损失、拆解费

### 2.3 关键量
**单个配件 i 供给一件合格件的期望成本**：
- 若 d_i=1（检测）：反复买+检直到获得合格件，期望成本 P_i = (c_i + t_i) / (1 - p_i)，且得到的件必合格。
- 若 d_i=0（不检测）：直接用1件，成本 c_i，合格概率 1-p_i。

**装配一件成品**（用1个配件1 + 1个配件2）：
- 配件期望成本 P_part = P_1 + P_2
- 装配费 c_a
- 成品检测费 t_f（若 d_f=1）

**装配后成品为合格品的概率**：
```
g_i = 1-p_i 若 d_i=0；g_i = 1 若 d_i=1
P_good = g_1 * g_2 * (1-p_f)      # 两配件都合格 且 装配不出错
P_bad  = 1 - P_good
```

### 2.4 单件成品全生命周期期望净成本（递推/固定点）

设 X = 交付1件合格成品到市场的期望总成本（不含售价收益），X_rec = 用回收配件时交付1件的期望总成本。

**首件装配（全新配件）**：
```
base = P_part + c_a + t_f*(d_f==1)
X = base
  + P_bad * 缺陷处理附加成本
  - P_good * s          # 合格件售出获得收益（负成本）
```

**缺陷处理附加成本**（对不合格成品）：
```
extra = (L 若 d_f==0 即流入市场被退回) + (r 若 d_r==1)
若 d_r==0（报废）：continuation = X        # 重做一件全新件
若 d_r==1（拆解）：continuation = X_rec 中的继续成本
```

**拆解回收（d_r=1）**：
- 支付拆解费 r，回收两件配件。回收件质量取决于首件是否检测过：
  - 配件i回收件合格概率 = 1-q_i，其中 q_i = 0 若 d_i=1；q_i = p_i 若 d_i=0
- 对回收配件按 d_i' 重新检测：
  - 若 d_i'=1：检测回收件，若合格直接用（0成本），若不合格丢弃并买新件。
    回收配件i期望成本 = q_i * (c_i+t_i)/(1-p_i)
  - 若 d_i'=0：直接用回收件，成本0，但该件合格概率 = 1-q_i。
- 用回收件重新装配（复用 c_a, t_f），装配后合格概率重新计算：
  ```
  g_i' = 1-q_i 若 d_i'=0；g_i' = 1 若 d_i'=1
  P_good' = g_1' * g_2' * (1-p_f)
  ```

### 2.5 固定点迭代求解

X 与 X_rec 相互依赖（拆解→回收→再装配→再可能拆解），用**固定点迭代**求解：
1. 初始化 X=0, X_rec=0；
2. 用当前 X_rec 算 X 的一次更新，用 X 算 X_rec 的一次更新；
3. 重复直到收敛（|ΔX|<1e-6）。

### 2.6 枚举最优决策
对每种情形，枚举所有决策组合 (d1,d2,df,dr,d1',d2') 共 2^6=64 种，用固定点迭代求每种组合的 X，取 X 最小者（即期望净成本最小）为最优。输出：最优决策、X、P_good、市场退回率、报废/拆解率等指标。

> 编程手注意：某些组合中 dr=1 时若首件配件未检测，回收件可能不合格，d_i'=1 能纠正；若 d_i'=0 则回收次品继续流入，成本更高。模型会自动比较。

## 三、问题3 动态规划模型

### 3.1 节点定义
对每个节点（配件 i、半成品 j、成品），定义：
- p_node：节点次品率（若检测后为0）
- t_node：检测成本
- assemble_cost：装配到上一级时的装配成本
- 父节点关系：哪些子节点装配成该节点

### 3.2 从成品向下递推
对每个节点定义 `V_node` = 从该节点起（含其子树）到最终成品售出的最小期望成本。

递推关系（类似问题2的固定点，但按树结构逐级）：
- 叶子（配件）：只有检测/不检测决策，无拆解（配件不拆解）。
- 中间（半成品/成品）：检测决策 + 不合格品拆解决策。

每个节点的成本 = 子节点供给成本 + 本节点装配成本 + 本节点检测成本 + (不合格处置)。

### 3.3 拓扑
```
成品 <- {半成品1, 半成品2, 半成品3}
半成品1 <- {配件1, 配件2, 配件3}
半成品2 <- {配件4, 配件5, 配件6}
半成品3 <- {配件7, 配件8}
```

### 3.4 编程实现建议
- 用递归函数 `cost(node, inspect_flag, dismantle_flag)`；
- 对每个节点枚举检测/拆解，比较期望成本取最小；
- 从成品向下递归，子节点成本作为输入；
- 输出：各节点最优检测决策、最优拆解决策、总最小期望成本、各节点合格率。

## 四、问题4 抽样估计下的稳健决策

### 4.1 思路
问题2/3中的次品率不再是确定值，而是通过问题1抽样方法估计得到。设抽检得次品数，次品率估计为 p̂，并给出置信区间。

### 4.2 处理方式（三选一或结合）
1. **点估计**：用 p̂ 直接替换原 p，重跑问题2/3的模型，得到决策方案。
2. **区间估计稳健**：用置信区间上界（悲观）与下界（乐观）分别求解，比较决策是否稳健；若决策对区间两端一致，则稳健。
3. **期望损失/蒙特卡洛**：对 p 在其后验分布上采样，计算每种决策组合的期望成本，取期望成本最小者。

### 4.3 输出
重新给出问题2的6种情形与问题3的决策方案，并说明抽样不确定性对决策的影响（稳健性分析）。
