====================================================================
  2024年高教社杯全国大学生数学建模竞赛  B题  问题1
  生产过程中的决策问题（一）—— 零配件抽样检测方案
====================================================================

一、问题重述
--------------------------------------------------------------------
供应商声称一批零配件（零配件1或零配件2）的次品率不超过某个标称
值 p0。企业拟采用抽样检测的方法决定是否接收这批零配件，检测费用
由企业自行承担。要求为企业设计检测次数尽可能少的抽样检测方案。

当标称值 p0 = 10% 时，针对以下两种情形分别给出具体结果：
  (1) 在 95% 的信度下认定零配件次品率超过标称值，则拒收这批零配件；
  (2) 在 90% 的信度下认定零配件次品率不超过标称值，则接收这批零配件。

二、模型假设
--------------------------------------------------------------------
1. 从大批零配件中随机抽取 n 件进行检测，抽样为有放回等价的无放回
   抽样（批量远大于 n，可视为独立重复试验）。
2. 每件零配件合格与否相互独立，且次品率恒为 p。
3. 检测是可靠的，即不会发生误检。
4. 只根据抽检样本判定，不依赖供应商信誉等先验信息。

三、符号说明
--------------------------------------------------------------------
  n   ：抽检件数
  X   ：抽检 n 件中的次品件数，X ~ Bin(n, p)
  p0  ：标称次品率，本题取 p0 = 10% = 0.10
  α   ：拒收检验的显著性水平，α = 1 - 0.95 = 0.05
  β   ：接收检验的显著性水平，β = 1 - 0.90 = 0.10
  cR  ：拒收判定的次品数阈值（X ≥ cR 时拒收）
  cA  ：接收判定的次品数阈值（X ≤ cA 时接收）

四、模型建立
--------------------------------------------------------------------
抽样检测属典型的计数型抽样验收问题。抽检 n 件，次品数服从二项分布：

        P(X = k) = C(n, k) p^k (1-p)^(n-k) ,  k = 0,1,...,n

(1) 拒收情形（情形1，95%信度）：
    原假设 H0：p ≤ p0（即批次合格）。当观测到次品数 X 较大时拒绝
    H0，判定次品率超标而拒收。为保证"批号实际合格时不被冤枉拒收"
    的概率不大于 α=0.05，须有：

        P(X ≥ cR | p = p0) = Σ_{k=cR}^{n} C(n,k) p0^k (1-p0)^(n-k) ≤ α

    在满足上式的前提下，为使检测次数最少，取最小的 n 及其对应的
    最小整数阈值 cR。

(2) 接收情形（情形2，90%信度）：
    当观测到次品数 X 很小时，认定次品率不超过标称值而接收。为保证
    判定有 90% 以上的把握，须有：

        P(X ≤ cA | p = p0) = Σ_{k=0}^{cA} C(n,k) p0^k (1-p0)^(n-k) ≤ β

    在满足上式的前提下，取最小的 n 及其对应的最大整数阈值 cA。

(3) 统一抽样方案：
    在实际生产中，两种情形需使用同一个抽检样本 n 进行判定。若
    X ≥ cR 则拒收；若 X ≤ cA 则接收；若 cA < X < cR 则无法在给定
    信度下作出判定，需继续抽样。为使检测次数尽可能少，取满足
    cA < cR 的最小 n。

五、模型求解
--------------------------------------------------------------------
采用 Python 程序（compute.py / compute2.py）枚举搜索。

(1) 拒收情形（情形1）单独最优：
    枚举 n = 1,2,...，寻找最小的 n 使存在 cR 满足 P(X≥cR|p0) ≤ 0.05。
    结果：n = 2，cR = 2。此时 P(X≥2 | 2, 0.10) = 0.01 ≤ 0.05。
    即仅需抽检 2 件，若 2 件均为次品，则在 95% 信度下认定次品率超标
    而拒收。

(2) 接收情形（情形2）单独最优：
    枚举 n = 1,2,...，寻找最小的 n 使存在 cA 满足 P(X≤cA|p0) ≤ 0.10。
    结果：n = 22，cA = 0。此时
        P(X≤0 | 22, 0.10) = 0.10^0·0.90^22 = 0.0985 ≤ 0.10。
    即需抽检 22 件，仅当 22 件全部合格（0 件次品）时，方可在 90%
    信度下认定次品率不超过 10% 而接收。
    经验证，n = 1~21 时均不存在满足 P(X≤cA)≤0.10 的整数阈值 cA
    （n 件全部合格的概率 0.90^n 均大于 0.10），故 n=22 为接收情形
    的最少检测数。

(3) 统一抽样方案（两情形共用同一 n）：
    枚举 n = 1,2,...，使同时存在 cA、cR 且 cA < cR。
    结果：n = 22，cA = 0，cR = 6。此时：
        P(X≤0 | 22, 0.10) = 0.0985 ≤ 0.10   （接收，90%信度）
        P(X≥6 | 22, 0.10) = 0.0182 ≤ 0.05   （拒收，95%信度）
        P(X≤5 | 22, 0.10) = 0.9818
    因此抽检 22 件：
        · 若次品数 X = 0        → 接收（90%信度下判定次品率不超标）；
        · 若次品数 X ≥ 6        → 拒收（95%信度下判定次品率超标）；
        · 若 1 ≤ X ≤ 5（概率约 0.8833）→ 置信度不足，需继续抽样。

六、结果汇总与讨论
--------------------------------------------------------------------
针对标称值 p0 = 10% 的两种情形，给出如下最少检测方案：

 情形1（拒收，95%信度）：
   抽检 n = 2 件，若 2 件均为次品（X=2）则拒收；
   拒收判定的第Ⅰ类风险 P(X≥2|p0)=0.01 < 0.05。

 情形2（接收，90%信度）：
   抽检 n = 22 件，若 22 件全部合格（X=0）则接收；
   接收判定把握 P(X≤0|p0)=0.0985 ≤ 0.10。

 统一方案（最少检测件数 n = 22）：
   抽检 22 件，X=0 接收，X≥6 拒收，1≤X≤5 需继续抽样。

说明：
  · 情形1单独只需要 n=2，这是因为"拒收"只需一个很小的样本来捕捉
    极端情况（两件均次品）；而"接收"要求以较高把握确认次品率低，
    必须用较大的样本（n=22）才能在低次品率下给出高置信结论。
  · 综合两种情形，统一采用 n=22 为最少检测次数。该方案既保证了对
    不合格批不误收（拒收风险），又保证了对合格批不误拒（接收把握），
    符合题目"检测次数尽可能少"的要求。
  · 当出现 1~5 件次品的模糊区间时，应追加抽样（可对剩余批次继续
    按同一规则抽检，累计判定），直至满足其中一种信度要求。

七、模型评价
--------------------------------------------------------------------
优点：基于二项分布建立计数型抽样验收模型，模型简洁、可解析求优，
      计算复杂度低，能给出明确的最少检测数。
不足：假设次品率为固定常数且批次均匀，未考虑抽检成本与错收/错拒
      的经济损失权衡；若需进一步优化，可引入损失函数构建贝叶斯
      决策模型，或扩展到问题4中的序贯抽样方案。
