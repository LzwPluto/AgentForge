问题1论文（抽样检测方案设计）

════════════════════════════════════════════════════════════════

摘  要

　　针对电子产品生产过程中供应商零配件质量的抽样验收问题，本文建立了基于二项分布与假设检验思想的抽样检测模型，为企业设计了检测次数尽可能少的抽样方案。

　　本文的核心思路是：设一批零配件的次品率为 p，随机抽取 n 件，检出次品数 X 服从二项分布 B(n,p)。通过临界值 c 建立"拒收/接收"判据，使得在不同信度要求下，抽样方案能对"次品率是否超过标称值"给出可靠判定。以标称值 p0=10% 为临界点，将问题转化为对二项分布尾概率的精确求解，通过逐 n 搜索寻找满足信度要求的最小样本量。

　　最终得到两个抽样方案：
　　（1）在 95% 信度下认定次品率超过标称值则拒收：最小样本量 n=29，抽样判据为"检出≥1件次品即拒收"；
　　（2）在 90% 信度下认定次品率不超过标称值则接收：最小样本量 n=1，抽样判据为"单件合格即接收"。

　　本文对方案的有效性、误判概率及稳健性进行了系统分析，并给出了补充性的备选方案讨论，为企业实际抽样验收提供了清晰、可操作的决策依据。

关键词：抽样检测；二项分布；假设检验；最小样本量；信度；次品率

════════════════════════════════════════════════════════════════

一、问题重述

　　某企业生产某种电子产品，需向供应商购买零配件。供应商声称一批零配件的次品率不会超过某个标称值。企业准备采用抽样检测方法决定是否接收这批零配件，检测费用由企业自行承担。请为企业设计检测次数尽可能少的抽样检测方案。

　　若标称值为 10%，针对以下两种情形分别给出具体结果：
　　（1）在 95% 的信度下认定零配件次品率超过标称值，则拒收这批零配件；
　　（2）在 90% 的信度下认定零配件次品率不超过标称值，则接收这批零配件。

　　本问题要求：在给定信度要求下，确定最小的抽样检测次数 n 及相应的判定规则（临界值），使企业能以足够把握对整批零配件作出接收或拒收的决策，同时尽量节省检测成本。

════════════════════════════════════════════════════════════════

二、问题分析

　　本问题的实质是一个基于抽样信息的统计检验问题。企业无法逐一检测全部零配件（成本过高），只能抽取少量样本，依据样本中的次品信息推断整批零配件的次品率是否超标，从而决定接收或拒收。

　　设随机抽取 n 件零配件进行检测，其中次品数为 X。在零配件相互独立的前提下，X 服从二项分布 B(n,p)。给定标称值 p0=10%，企业需要：

　　（1）情形(1)：当实际次品率超过标称值 p0 时，有 95% 的把握认定并拒收。即要求抽样方案在 p=p0 处对"超标"有足够高的识别能力——当真实次品率不低于 p0 时，拒收概率不小于 95%。等价地，在 p=p0 处拒收（误拒合格批）的概率不超过 5% 的补，即"拒收判定"的置信度达 95%。

　　（2）情形(2)：当实际次品率不超过标称值 p0 时，有 90% 的把握认定并接收。即要求在 p=p0 处"接收"的把握达 90%，即接收概率不小于 90%。

　　由于二项分布的尾概率随 n 单调变化，我们可以通过逐 n 搜索，寻找满足信度要求的最小样本量 n 及相应的临界值 c，从而在保证判定可靠性的前提下，使检测次数最少、检测成本最低。

════════════════════════════════════════════════════════════════

三、模型假设

　　（1）各零配件的质量相互独立，任一件零配件为次品的概率恒为 p；
　　（2）抽样检测为不放回抽样，但批总量远大于样本量 n，可近似视为有放回的独立抽样，故 X~B(n,p)；
　　（3）检测过程无误差，即检测结果能准确判定每件零配件是否合格；
　　（4）供应商声称的标称值 p0=10% 为本问题所有情形的判定基准；
　　（5）每次检测成本固定，企业追求在满足信度约束下使检测次数尽可能少。

════════════════════════════════════════════════════════════════

四、符号说明

| 符号 | 含义 |
|:---|:---|
| p | 一批零配件的真实次品率 |
| p0 | 供应商声称的标称次品率（本问题 p0=10%） |
| n | 抽样检测的件数（待求的最小样本量） |
| X | 抽取 n 件中检出的次品数，X~B(n,p) |
| c | 判定临界值：X>c 时拒收，X≤c 时接收 |
| α | 显著性水平（第一类错误概率） |
| β | 第二类错误概率（漏判） |

════════════════════════════════════════════════════════════════

五、模型建立

　　随机抽取 n 件零配件进行检测，其中次品数 X 服从二项分布：

　　　　P(X=k) = C(n,k) · p^k · (1-p)^(n-k)，　k=0,1,…,n

　　其累积分布函数为：

　　　　P(X≤c) = Σ_{k=0}^{c} C(n,k) · p^k · (1-p)^(n-k)

　　引入判定临界值 c：若样本中检出次品数 X>c，则认为该批零配件次品率超标，予以拒收；若 X≤c，则认为次品率未超标，予以接收。

　5.1 情形(1)：95% 信度下认定超标则拒收

　　本情形要求：当实际次品率超过标称值（即 p≥p0）时，企业有 95% 的把握认定次品率超标并拒收。判定判据为"X>c 则拒收"。

　　在最贴近标称值的临界情形 p=p0 处，为使拒收具有 95% 的置信度，需满足：

　　　　P(X>c | p=p0) ≥ 0.95

　　等价地：

　　　　P(X≤c | p=p0) ≤ 0.05

　　即在 p=p0 时，误拒合格批（本应接收却拒收）的概率不超过 5%。据此，对给定 n，选择使上述不等式成立的最大临界值 c；再对 n 从小到大搜索，取第一个满足条件的最小 n，即为检测次数最少的抽样方案。

　5.2 情形(2)：90% 信度下认定不超标则接收

　　本情形要求：当实际次品率不超过标称值（即 p≤p0）时，企业有 90% 的把握认定次品率未超标并接收。判定判据为"X≤c 则接收"。

　　在临界情形 p=p0 处，为使接收具有 90% 的置信度，需满足：

　　　　P(X≤c | p=p0) ≥ 0.90

　　即当真实次品率恰为标称值时，抽样方案能正确判为接收的概率不低于 90%。据此，对给定 n，选择满足上述不等式的最小临界值 c；再对 n 从小到大搜索，取第一个满足条件的最小 n。

════════════════════════════════════════════════════════════════

六、模型求解

　6.1 情形(1)：95% 信度拒收方案

　　对 n=1,2,3,… 逐次搜索，对每个 n 寻找最大临界值 c 使 P(X≤c|p=0.10)≤0.05。计算结果：

　　当 n=29 时，取 c=0，有：

　　　　P(X≤0 | p=0.10) = (1-0.10)^29 = 0.9^29 = 0.04710129

　　　　0.04710129 ≤ 0.05，满足条件；

　　　　P(X>0 | p=0.10) = 1 - 0.04710129 = 0.95289871 ≥ 0.95

　　因此，情形(1)的最小样本量为 n=29，拒收判据为：检出≥1 件次品（X≥1）即拒收。

　　　　抽样方案：随机抽取 29 件零配件进行检测，
　　　　　　　　  若检出的次品数 X≥1，则拒收整批零配件；
　　　　　　　　  若全部合格（X=0），则接收整批。

　　该方案在不同真实次品率下的拒收概率（检验功效）如下表：

| 真实次品率 p | 拒收概率 P(X>0) |
|:---:|:---:|
| 5% | 0.7741 |
| 8% | 0.9109 |
| 10% | 0.9529 |
| 12% | 0.9755 |
| 15% | 0.9910 |
| 20% | 0.9985 |
| 30% | 1.0000 |

　　可见：当实际次品率恰为标称值 10% 时，拒收概率为 95.29%，满足"95% 信度下认定超标则拒收"；当实际次品率进一步升高时，拒收概率迅速趋近于 1，说明方案对真正超标的批次具有很强的检出能力。

　6.2 情形(2)：90% 信度接收方案

　　对 n=1,2,3,… 逐次搜索，对每个 n 寻找最小临界值 c 使 P(X≤c|p=0.10)≥0.90。计算结果：

　　当 n=1 时，取 c=0，有：

　　　　P(X≤0 | p=0.10) = (1-0.10)^1 = 0.90

　　　　0.90 ≥ 0.90，满足条件。

　　因此，情形(2)的最小样本量为 n=1，接收判据为：单件合格（X=0）即接收。

　　　　抽样方案：随机抽取 1 件零配件进行检测，
　　　　　　　　  若该件合格（X=0），则接收整批零配件；
　　　　　　　　  若该件为次品（X=1），则拒收整批。

　　该方案在不同真实次品率下的接收概率如下表：

| 真实次品率 p | 接收概率 P(X≤0) |
|:---:|:---:|
| 2% | 0.9800 |
| 5% | 0.9500 |
| 8% | 0.9200 |
| 10% | 0.9000 |
| 12% | 0.8800 |
| 15% | 0.8500 |

　　可见：当实际次品率恰为标称值 10% 时，接收概率为 90%，满足"90% 信度下认定不超标则接收"；当实际次品率低于标称值时，接收概率升高（如 p=5% 时为 95%），正确接收合格批的把握增大。

七、结果分析与稳健性讨论

　7.1 结果汇总

| 情形 | 信度要求 | 最小样本量 n | 临界值 c | 判定规则 |
|:---:|:---:|:---:|:---:|:---|
| (1) | 95% 信度拒收 | 29 | 0 | 检出≥1件次品即拒收 |
| (2) | 90% 信度接收 | 1 | 0 | 单件合格即接收 |

　7.2 建模理解说明

　　两个情形是相互独立的两个抽样方案，分别针对"拒收"与"接收"两种决策目标。值得注意的是，若将两者视为同一方案的接收域与拒绝域，则情形(1)要求 P(X≤c)≤0.05，情形(2)要求 P(X≤c)≥0.90，二者在数学上矛盾，故赛题要求"分别给出具体结果"，即分别设计两个独立方案，这与模型求解一致。

　7.3 稳健性讨论

　　情形(2)取 n=1 在数学上是"检测次数尽可能少"约束下的严格最小解（p=10% 时单件合格概率恰为 90%）。但实际生产中仅凭单件合格即接收整批，工程上风险较大。若企业希望在更高稳健性下决策，可采用增大的样本量方案。例如：

　　（1）n=22、c=4：在 p=10% 时接收概率 P(X≤4)=93.79%≥90%，同时临界次品率 4/22≈18.2%，方案对合格批有更高识别能力；
　　（2）n=18、c=3：在 p=10% 时接收概率 90.18%，为满足 90% 信度的较大样本备选方案之一。

　　企业可根据检测成本与质量风险的权衡，在"最小样本量"（n=1）与"更高稳健性"方案之间选择。

　7.4 模型优点与不足

　　优点：模型以精确的二项分布概率计算为基础，避免了正态近似的误差，结果精确可靠；逐 n 搜索逻辑清晰，便于程序实现与推广；对两种情形给出了独立、明确、可操作的判定规则。

　　不足：情形(2)的 n=1 方案在工程上偏激进，论文已通过稳健性讨论给出补充；模型假设检测无误差、批总量远大于样本量，在极端情形（小批量、检测有误差）下需进一步修正。

八、模型评价与推广

　　本文建立的抽样检测模型基于二项分布，能够针对不同信度要求精确求解最小样本量与判定临界值，具有较强的普适性。该模型可推广至：
　　（1）不同标称值 p0 的抽样验收问题；
　　（2）考虑检测成本约束下的最优抽样方案设计；
　　（3）引入序贯抽样（分阶段抽样）以进一步降低平均检测次数；
　　（4）结合损失函数，构建使总期望成本最小化的抽样方案。

　　综上，本文为企业在给定信度要求下设计"检测次数尽可能少"的抽样验收方案提供了清晰、可靠的数学模型与数值解。

附录：问题1求解代码（Python）

import math
from math import comb

def binom_pmf(k, n, p):
    return comb(n, k) * (p ** k) * ((1 - p) ** (n - k))

def binom_cdf(k, n, p):
    return sum(binom_pmf(i, n, p) for i in range(k + 1))

def case1(p0=0.10, confidence=0.95):
    # 情形(1)：P(X>c|p=p0)>=0.95，即 P(X<=c|p=p0)<=0.05，找最小 n
    for n in range(1, 500):
        c = -1
        while c + 1 <= n and binom_cdf(c + 1, n, p0) <= (1 - confidence) + 1e-12:
            c += 1
        if c >= 0:
            return n, c, 1 - binom_cdf(c, n, p0)
    return None

def case2(p0=0.10, confidence=0.90):
    # 情形(2)：P(X<=c|p=p0)>=0.90，找最小 n
    for n in range(1, 500):
        c = 0
        while c <= n and binom_cdf(c, n, p0) < confidence - 1e-12:
            c += 1
        if c <= n:
            return n, c, binom_cdf(c, n, p0)
    return None

# 情形(1)
n1, c1, pr = case1()
print(f"情形(1): n={n1}, c={c1}, P(X>{c1}|p=0.10)={pr:.8f}")

# 情形(2)
n2, c2, pa = case2()
print(f"情形(2): n={n2}, c={c2}, P(X<={c2}|p=0.10)={pa:.8f}")

# 运行结果：
# 情形(1): n=29, c=0, P(X>0|p=0.10)=0.95289871
# 情形(2): n=1,  c=0, P(X<=0|p=0.10)=0.90000000
