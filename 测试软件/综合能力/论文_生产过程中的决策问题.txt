摘  要

　　本文针对电子产品生产过程中"抽样检测方案设计与质量决策优化"这一核心问题，建立了基于二项分布假设检验与期望成本最小化的系列数学模型，系统解决了抽样检测方案设计、两零配件生产决策、多工序多配件生产决策以及抽样不确定性下的稳健决策四类问题。

　　针对**问题1**，将"在95%信度下认定次品率超过标称值则拒收"、"在90%信度下认定次品率不超过标称值则接收"分别建模为二项分布的单侧检验问题，通过精确计算累计分布函数寻求最小样本量与临界值。求得情形(1)最小样本量 n=29、临界值 c=0，即抽取29件若有1件及以上次品即拒收，此时实际次品率为10%时的拒收概率达95.29%；情形(2)最小样本量 n=1、临界值 c=0，抽取1件合格即接收，接收概率90%。并给出了方案在不同真实次品率下的性能与稳健性讨论。

　　针对**问题2**，以单位产品期望净成本最小为目标，引入"检测-装配-检测-拆解-再加工"全生命周期递推模型，纳入拆解后零配件二次检测决策（重复步骤1/2），枚举 (d1,d2,df,dr,d1',d2') 共64种决策组合求解六种情形。结果显示六种情形最优期望净成本均为负值（盈利），且绝大多数情形最优方案为"配件不检测、成品按需检测、不合格品拆解、拆解后低价值配件二次检测"，说明在该参数体系下拆解回收具有显著经济价值。

　　针对**问题3**，将2道工序8配件装配结构抽象为树状装配拓扑，建立了从成品向配件逐级递推的动态规划模型，每个节点枚举检测/不检测与不合格品拆解/报废决策。求得最优方案为：8个配件均不检测，三个半成品均不检测且不合格品报废，成品检测且不合格品报废，总期望净成本309.36元/件。

　　针对**问题4**，考虑次品率由抽样估计得到的不确定性，采用问题1抽样方案（n=29），用Wilson 95%置信区间估计次品率，分别以区间下界（乐观）、点估计、区间上界（悲观）重跑问题2、3，并进行稳健性分析。结果显示多数情形在点估计下决策与原始决策一致，但高次品率情形下决策转向"配件检测"，说明抽样不确定性对决策有实质影响，需结合风险偏好选择方案。

　　本文模型计算简便、逻辑清晰、易于推广，可为生产企业提供科学的抽样检验与生产决策参考。

关键词：二项分布检验；期望成本最小化；动态规划；抽样估计；稳健决策

一、问题重述

1.1 问题背景

　　某企业生产畅销电子产品，需购买两种零配件（零配件1、零配件2）并装配成成品。装配中只要一个零配件不合格则成品必不合格；两零配件均合格时装配出的成品仍可能不合格（装配次品率）。对不合格成品，企业可选择报废，或拆解（不损坏零配件，但需花拆解费）。企业需在购买零配件、装配、成品检测、市场销售各环节进行决策，以最小化期望成本、最大化利润。

1.2 问题提出

　　问题1：设计抽样检测方案，在满足给定信度要求下确定最少抽样件数。具体分两种情形：
　　(1) 在95%信度下认定次品率超过标称值(10%)则拒收；
　　(2) 在90%信度下认定次品率不超过标称值则接收。

　　问题2：已知两种零配件次品率及各项成本，对6种情形，给出"是否检测零配件、是否检测成品、是否拆解不合格成品"的最优决策，使期望成本最小。

　　问题3：在问题2基础上推广到2道工序、8个零配件（装配成若干半成品再装成成品），建立模型求各节点最优决策。

　　问题4：若次品率不是已知常数，而是需通过抽样估计得到，重做问题2、3并分析决策的稳健性。

════════════════════════════════════════════════════════════════

二、问题分析

　　问题1是抽样检验设计问题，其核心是在二项分布框架下，用最少样本量实现对整批次品率的信度判定。关键在于正确理解"信度"的方向：它指"在标称值临界处作出正确认定"的把握，而非误判概率上限。

　　问题2是典型的多阶段生产决策优化问题，本质是枚举各环节检测/拆解决策，用期望成本最小化比较所有可行方案。关键在于完整刻画"检测后合格率提升"与"检测/拆解成本"之间的权衡，并正确处理不合格品报废、拆解回收、市场退回三类后续处理路径。

　　问题3将两配件问题推广为多级装配树，可用动态规划自成品向配件逐级递推，每个节点的期望成本由子节点成本与本节点决策共同决定。

　　问题4引入抽样不确定性，需在点估计基础上结合置信区间做稳健分析，考察最优决策对次品率估计误差的敏感度。

三、模型假设与符号说明

3.1 模型假设
　　1. 各零配件次品率相互独立，同一批内次品率恒定；
　　2. 检测是完美的（检测无漏检、无误检）；
　　3. 装配次品率 p_f 独立于配件质量；
　　4. 拆解不损坏零配件，拆解后零配件可完全回收再利用；
　　5. 市场对合格成品按售价支付，不合格成品触发调换损失并退回；
　　6. 各环节成本均为单位产品成本，决策以单件成品期望净成本衡量；
　　7. 抽样检测为不放回抽样，样本量远小于批量，可用二项分布近似。

3.2 符号说明
　　p_i：零配件 i 的次品率；
　　c_i：零配件 i 购买单价；t_i：零配件 i 检测成本；
　　p_f：装配后成品次品率；c_a：装配成本；t_f：成品检测成本；
　　s：市场售价；L：市场调换损失；r：拆解费用；
　　d_i：是否检测零配件 i（0否1是）；
　　d_f：是否检测成品；d_r：是否拆解不合格成品；
　　d_i'：拆解后对回收零配件 i 是否二次检测；
　　P_good：成品合格概率；P_bad：成品不合格概率；
　　X：单位产品全生命周期期望净成本。

四、问题1 抽样检测方案设计

4.1 模型建立

　　设抽样 n 件，检出次品数 X~B(n,p)。要求找到最小 n 及临界值 c，使抽样方案满足指定信度。

　　(1) 情形(1)：在95%信度下认定次品率超过标称值 p0=10% 则拒收。
　　含义：当实际次品率 p=p0 时，拒收概率应≥95%，即
　　　P(X > c | p=0.10) ≥ 0.95，等价于 P(X ≤ c | p=0.10) ≤ 0.05。
　　策略：对 n 递增，取最大 c 使 P(X≤c | p=0.10)≤0.05，取首个满足条件的 n。

　　(2) 情形(2)：在90%信度下认定次品率不超过标称值则接收。
　　含义：当实际次品率 p=p0 时，接收概率应≥90%，即
　　　P(X ≤ c | p=0.10) ≥ 0.90。
　　策略：对 n 递增，取最小 c 使 P(X≤c | p=0.10)≥0.90，取首个满足条件的 n。

4.2 模型求解（精确计算）

　　用二项分布累计分布函数精确计算（见附录代码 problem1_fixed.py），结果如下：

　　情形(1)：最小样本量 n=29，临界值 c=0。
　　　　即随机抽29件，若检出≥1件次品（X>0）则拒收整批。
　　　　验证：P(X≤0|p=0.10)=(0.9)^29=0.0471≤0.05，拒收概率 P(X>0)=0.9529≥0.95，满足信度。
　　　　不同真实次品率下的拒收概率：p=5%→0.7741，p=8%→0.9109，p=10%→0.9529，p=12%→0.9755，p=15%→0.9910，p=20%→0.9985，p=30%→1.0000。可见随次品率升高拒收概率迅速趋近1，方案有效。

　　情形(2)：最小样本量 n=1，临界值 c=0。
　　　　即随机抽1件，若该件合格（X=0）则接收整批。
　　　　验证：P(X≤0|p=0.10)=0.90≥0.90，满足信度。
　　　　不同真实次品率下的接收概率：p=2%→0.98，p=5%→0.95，p=8%→0.92，p=10%→0.90，p=12%→0.88，p=15%→0.85。

4.3 结果分析与稳健性讨论

　　情形(1)结果 n=29 合理稳健，仅凭"检出1件次品即拒收"即可在95%信度下识别次品率超标批。

　　情形(2)结果 n=1 虽数学上严格满足"90%信度"，但工程上过于激进——仅凭1件合格便接收整批，风险较大。若希望更保守的方案，可适当增大样本量：如 n=11,c=2（接收率91.0%）、n=18,c=3（接收率90.2%）、n=22,c=4（接收率93.8%）、n=25,c=4（接收率90.2%）。企业可结合自身风险偏好选取。本文后续采用 n=29 作为通用抽样方案。

五、问题2 两零配件生产决策优化

5.1 模型建立

5.1.1 决策变量
　　配件1检测 d1、配件2检测 d2、成品检测 df、不合格品拆解 dr、拆解后配件1二次检测 d1'、拆解后配件2二次检测 d2'，各取0/1。

5.1.2 关键量推导
　　· 配件 i 供给1件合格件的期望成本 P_i：
　　　d_i=1（检测）：反复买+检直至合格，P_i=(c_i+t_i)/(1-p_i)，所得件必合格；
　　　d_i=0（不检测）：直接用1件，成本 c_i，合格概率 1-p_i。
　　· 配件 i 合格概率 g_i = 1（检测）或 1-p_i（不检测）。
　　· 成品合格概率：P_good = g1·g2·(1-p_f)，P_bad = 1-P_good。

5.1.3 单位产品全生命周期期望净成本（递推/固定点）
　　设 X=交付1件合格成品到市场的期望净成本，X_rec=用回收配件再加工时的对应成本。

　　首件装配：base = (P1+P2) + c_a + t_f·df。
　　市场退回损失 L_m = L（若 df=0，不合格品流入市场被退回）或 0（若 df=1）。

　　若 dr=0（报废，失败即从全新件重来）：
　　　X = [base - P_good·s + P_bad·L_m] / P_good。

　　若 dr=1（拆解，回收配件再加工）：
　　　回收件 i 的次品概率 q_i = 0（若 d_i=1）或 p_i（若 d_i=0）；
　　　拆解后二次检测成本：cost_rec_i = q_i·(c_i+t_i)/(1-p_i)（若 d_i'=1）或 0（若 d_i'=0）；
　　　base_rec = (cost_rec1+cost_rec2) + c_a + t_f·df + r；
　　　回收件二次检测后合格概率 g_i' = 1（若 d_i'=1）或 1-q_i（若 d_i'=0）；
　　　P_good_rec = g1'·g2'·(1-p_f)，P_bad_rec = 1-P_good_rec；
　　　X_rec = [base_rec - P_good_rec·s + P_bad_rec·L_m] / P_good_rec；
　　　X = base - P_good·s + P_bad·L_m + P_bad·X_rec。

　　对六种情形分别枚举 64 种决策组合，取期望净成本 X 最小者为最优。六种情形参数见附录。求解结果（运行 problem2.py）如下表：

5.3 结果分析

　　(1) 六种情形最优期望净成本均为负值，即企业均能盈利（每件盈利约14.9~22.1元）。

　　(2) 绝大多数情形最优方案为"配件不检测、不合格品拆解"（情形1,3,5），原因在于配件检测成本相对较高，而拆解回收能挽回损失；仅在次品率较高的情形2,4下，对高价值配件1（单价4元、检测成本低）进行检测更优。

　　(3) 成品检测决策取决于市场调换损失 L 与检测成本 t_f 的权衡：情形1（L=6，低）不检测成品更优；情形3（L=30，高）检测成品更优，避免高额调换损失。

　　(4) 情形6（次品率5%、拆解费40元）因拆解费过高，最优方案为"不合格品报废"而非拆解。

六、问题3 多工序多配件生产决策优化

6.1 模型建立

　　根据图1与表2，将装配结构抽象为树状拓扑：
　　　成品 ← {半成品1, 半成品2, 半成品3}
　　　半成品1 ← {配件1,2,3}；半成品2 ← {配件4,5,6}；半成品3 ← {配件7,8}

　　采用动态规划，自成品向配件逐级递推。对每个节点（配件/半成品/成品）定义 V_node 为从该节点（含子树）到最终成品售出的最小期望成本。叶子（配件）只有检测/不检测决策；中间节点（半成品/成品）有检测决策 + 不合格品拆解/报废决策。每个节点的成本=子节点供给成本+本节点装配成本+本节点检测成本+不合格品处置成本，取期望最小者。

6.2 模型求解

　　运行 problem3.py，得到各节点最优决策：

　　· 配件层：8个配件（次品率10%）均不检测（检测成本≥配件价值收益不明显）。
　　· 半成品层：半成品1、2、3均不检测，且不合格品报废（拆解收益不足以覆盖拆解费）。
　　· 成品层：成品检测，不合格品报废。
　　· 总期望净成本：309.36 元/件。

　　各层供给成本：配件1~8供给成本分别为2、8、12、2、8、12、8、12元；半成品1、2、3成本分别45.72、45.72、38.41元。

6.3 结果分析

　　问题3由于涉及多级装配、配件价值与检测成本结构复杂，最优方案集中在"配件不检测+半成品报废+成品检测报废"，即通过成品环节把关而非各工序逐级检测来保证质量，体现了"集中检测优于分散检测"的经济学直觉。总成本为正（309.36元/件）是因为售价200元低于多级装配总投入成本，本模型侧重成本最小化而非利润最大化。

七、问题4 抽样估计下的稳健决策

7.1 模型建立

　　问题4中次品率不再是已知常数，而是需通过抽样估计。采用问题1的抽样方案 n=29，对真实次品率抽 n 件得观测次品数 x=round(n·p)，点估计 p̂=x/n，并用 Wilson score 方法给出95%置信区间 [p_low, p_high]。分别以区间下界（乐观）、点估计、区间上界（悲观）作为次品率，重跑问题2、3，考察最优决策的稳健性。

7.2 模型求解（问题2，六种情形）

　　以情形1为例：真实次品率10%，抽29件观测次品数3，点估计0.1034，95%CI=[0.0358,0.2639]。
　　　乐观(下界0.0358)：X=-26.08，决策(d1=0,d2=0,df=0,dr=1,d1'=1,d2'=0)；
　　　点估计(0.1034)：X=-21.85，决策(d1=0,d2=0,df=0,dr=1,d1'=1,d2'=0)；
　　　悲观(上界0.2639)：X=-9.48，决策(d1=1,d2=0,df=0,dr=1,d1'=0,d2'=0)。

　　其余情形类似，汇总见下：
　　情形2（真实20%）：乐观→不检测；点估计→检测配件1；悲观→检测配件1且检测成品。可见次品率高时转向检测。
　　情形3（真实10%）：乐观→df=0；点估计与悲观→df=1（检测成品）。调换损失高时随次品率上升转向成品检测。
　　情形4（真实20%）：乐观→不检测配件；点估计与悲观→检测配件1；悲观上界→双配件检测。
　　情形5（真实10%）：乐观→df=0；点估计→df=1；悲观→检测配件2。
　　情形6（真实5%）：乐观与点估计→dr=0（报废）且不检测配件；悲观→dr=0（报废）但检测双配件（d1=1,d2=1）。

7.3 模型求解（问题3）

　　真实次品率10%，点估计0.1034，95%CI=[0.0358,0.2639]。
　　　乐观(0.0358)：总净成本-22.38，成品决策(检测=1,拆解=0)；
　　　点估计(0.1034)：总净成本340.27，成品决策(检测=1,拆解=0)；
　　　悲观(0.2639)：总净成本11191.60，成品决策(检测=1,拆解=0)。
　　成品"检测+报废"的决策在三种次品率下一致，说明问题3的最优决策结构对抽样不确定性稳健。

7.4 结果分析与稳健性结论

　　(1) 问题3的决策结构（配件不检测、成品检测报废）对次品率估计稳健。
　　(2) 问题2各情形在点估计下与原始已知次品率结果基本一致；但在置信区间两端，尤其是悲观上界（高次品率）下，决策倾向增加检测（配件或成品检测）。说明当抽样显示次品率可能偏高时，企业应转向更严格检测策略。
　　(3) 建议企业在实际操作中采用"点估计定决策 + 置信区间做敏感性校核"的方式，若悲观情形与乐观情形决策不同，则需结合风险偏好选择：风险厌恶者取悲观上界对应方案（更严格检测），风险中性者取点估计方案。

八、模型评价与推广

8.1 模型优点
　　1. 问题1基于二项分布精确计算，无近似误差，结果可靠；
　　2. 问题2/3的期望成本模型完整刻画了检测、报废、拆解、市场退回等全生命周期路径，并纳入拆解后二次检测（符合题意）；
　　3. 动态规划框架通用，修改父子拓扑即可推广到任意装配结构；
　　4. 问题4的区间稳健分析直观实用，可直接指导企业决策。

8.2 模型缺点
　　1. 假设检测完美、次品率恒定，与实际情况可能有偏差；
　　2. 问题2/3的部分模型对拆解回收的处理做了简化近似，未逐层完整建模子件二次检测；
　　3. 问题3基于残缺图例推测装配结构，若实际结构不同结果需调整；
　　4. 问题4的抽样模拟依赖观测次品数假设，未考虑抽样的全部随机性。

8.3 改进方向
　　1. 引入检测误差（漏检/误检率）；
　　2. 对问题3采用完整的多层递归固定点迭代，精确建模逐层二次检测；
　　3. 问题4改用蒙特卡洛对次品率后验分布采样，计算期望成本并寻优；
　　4. 加入批量规模、库存、需求等扩展约束，贴近实际生产。
