# 🚀 OpenCode Multi-Agent Collaborative Platform (TUI Edition)

> **现代化多智能体圆桌接力协同开发与创作平台**  
> 支持 **多 API 供应商管理** · **全员沙箱工具平权** · **顺序循环圆桌接力** · **深度思考可视化** · **独立隔离 Python 沙箱** · **历史会话自动归档**

---

## 🌟 核心特性概览

### 1. 🤖 5 槽位多角色圆桌接力 (Round-Robin Group Chat)
- **自由定制分工**：支持最多 5 位 AI 协同成员（如作家、审核员、编程手、论文手、总策划或自定义角色）；
- **全景共享黑板**：场内所有成员的发言、思考过程、工具调用与代码改动对全场实时公开透明；
- **全自动交接接力**：成员按槽位绝对顺序轮流发言并执行操作，自动推进复杂任务直至目标圆满达成。

### 2. 🧠 深度思考可视化与强度调控 (Deep Thinking Mode)
- **实时思考折叠框**：大模型（如 DeepSeek-R1 / Qwen-QwQ）的推理过程实时流式折叠展示，附带精准字数统计；
- **思考强度三档可调**：支持在设置（`F1`）中为每个角色独立配置思考模式：
  - `深度思考 (Deep)`：全量推理推导；
  - `轻度思考 (Lite)`：限制 1024 Token 轻量思考；
  - `关闭思考 (Off)`：零思考延迟，极速出字；
- **只思考不回答自动补齐**：若推理模型思考完毕后忘记输出正文，系统自动触发零延迟极速补齐，绝不留白。

### 3. 🗳️ 全员在线民主表决闭环 (Democratic Consensus Voting)
- 当任意成员认为目标已达成时，系统自动启动**【全员在线表决】**程序；
- 在场所有 AI 开启深度思考逐项审查交付成果；
- **全票赞成方可圆满交付**；若有异议，系统自动将所有修改意见汇总为**强制改进清单**，注入下一轮接力中直至彻底解决！

### 4. 🛡️ 内置独立 AI Python 测试沙箱 (`sandbox_env`)
- **宿主系统物理隔离**：系统在 `sandbox_env/` 下内置专供 AI 使用的独立虚拟环境；
- **命令强环境变量注入**：AI 执行 `python ...`、`pip install ...` 等终端命令时，自动绑定沙箱环境，绝不污染或破坏宿主系统与主程序。

### 5. 🔌 多 API 供应商统一管理 & 下拉联动
- 支持 **DeepSeek、OpenAI、阿里通义千问、硅基流动、Ollama 本地大模型** 等任意兼容 OpenAI 接口的供应商；
- 供应商填写的模型列表自动解析，并在角色槽位中以**下拉菜单（Select）形式联动呈现**，无需手动重复输入，彻底杜绝拼写错误。

### 6. 📜 历史会话自动归档与即时预览 (History Manager)
- 每次任务执行完毕或终止时，系统自动在 `history/` 目录生成两份文件：
  - 📄 `session_*.md`：排版精美的 Markdown 全景会议纪要；
  - 💾 `session_*.json`：完整的结构化上下文数据；
- 按 **`F2`** 即可随时打开历史会话管理器，支持直接阅读完整纪要与清理历史。

### 7. ⏸️ 中途暂停与人工介入指导 (Human-in-the-Loop)
- 协同过程中随时按 **`Ctrl+P`** 挂起会议；
- 您可在输入框中输入新的补充要求或方向纠偏，按下回车直接注入群聊黑板，由下一位 AI 成员响应推进。

## 🖥️ 快速开始 (Quickstart)

### 环境要求
- **操作系统**：Windows 10/11、macOS 或 Linux
- **Python 版本**：Python 3.10 及以上（推荐 Python 3.11 / 3.12）

---

### 🚀 方式一：Windows 一键启动（最推荐）

1. **解压压缩包** 到任意目录；
2. **双击运行 `run.bat`**：
   - 首次运行会自动检查环境、创建 Python 虚拟环境并自动安装所有依赖；
   - 自动启动 OpenCode 终端交互平台！
3. **配置 API Key**：
   - 启动后按键盘上的 **`F1`** 键（或点击右下角 `[⚙️ 设置]`）；
   - 在 **`🔑 API 供应商`** 标签中填入您的 DeepSeek / OpenAI / SiliconFlow 密钥并点击保存即可！

---

### 💻 方式二：命令行手动启动

```bash
# 1. 创建并激活虚拟环境
python -m venv .venv

# Windows 激活
.venv\Scripts\activate
# macOS / Linux 激活
source .venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动交互式 TUI 平台
python main.py
```

## ⌨️ 常用快捷键一览

| 快捷键 | 界面按钮 | 功能说明 |
| :--- | :--- | :--- |
| **`F1`** | `[⚙️ 设置]` | 打开 **API 供应商管理**、**5 角色槽位分工** 与 **工作区沙箱** 设置弹窗 |

| **`Ctrl + L`** | - | 清空当前屏幕实时滚动日志 |
| **`Ctrl + Q`** | - | 安全退出平台 |

## 💡 常见问题与技巧 (FAQ)

### Q1: 提示找不到 API Key 怎么办？
> 按 **`F1`** 进入设置，在第一个标签页中找到您的供应商（例如 `DeepSeek 官方`），在 `API Key` 输入框中填入您的密钥（如 `sk-...`），然后点击底部的 **`[💾 保存并应用配置]`** 即可。

### Q2: 如何修改某个角色的任务职责或更换模型？
> 按 **`F1`** 进入设置 ➔ 切换到 **`🤖 角色分工`** 标签 ➔ 点击顶部的槽位按钮（如 `槽位 1`、`槽位 2`）➔ 您可以自由修改角色名称、图标 Emoji、系统提示词（Prompt）、绑定的供应商与具体模型。

### Q3: AI 执行命令或写代码会影响我的电脑系统吗？
> **不会**。OpenCode 内置了强隔离的 `sandbox_env` 独立环境与工作区路径限制，AI 的所有文件创建、代码运行与包安装均限制在隔离沙箱中，宿主系统与主程序完全安全。
