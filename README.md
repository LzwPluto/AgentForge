# OpenCode Multi-Agent Collaborative Platform (TUI Edition)

🚀 **OpenCode** 是一个支持 **多 API 供应商统一管理**、**全员沙箱工具平权**、**顺序循环圆桌接力 (Sequential Round-Robin Group Chat)**、**全景共享群聊黑板** 与 **历史会话自动归档管理** 的现代化多 Agent 协同创作与开发平台。

---

## 🌟 核心特性概览

### 1. 动态模型下拉自动罗列（免手动二次输入）
- 在 API 供应商中配置的模型列表（支持 **顿号 `、`、英文逗号 `,`、中文逗号 `，` 或空格** 分割）；
- 在角色槽位配置中，**绑定模型自动以下拉菜单（Select）形式呈现**；
- 切换供应商时，模型下拉框实时联动更新，用户直接点击选择即可，杜绝拼写错误。

### 2. 历史会话自动持久化归档与管理 (History Manager)
- **自动归档**：每次协同接力执行完毕后，系统自动在 `history/` 目录生成两份文件：
  - 📄 `session_YYYYMMDD_HHMMSS.md`：排版精美的 Markdown 全景会议纪要；
  - 💾 `session_YYYYMMDD_HHMMSS.json`：完整的结构化上下文数据。
- **历史管理弹窗 (按 `F2` 或点击 `[📜 历史]`)**：
  - 左侧浏览所有历史协同任务、归档时间与接力轮数；
  - 右侧即时预览完整的 Markdown 对话纪要；
  - 提供 **`[🗑️ 删除此会话]`** 与 **`[🧹 清空全部历史]`** 管理功能。

### 3. 顺序循环圆桌协同 (Round-Robin Sequential Loop)
- **按槽位绝对顺序轮流发言**：槽位 1 ➔ 槽位 2 ➔ (其它槽位) ➔ 槽位 1 ➔ ...；
- **全景轮次实时看板**：顶部顶栏与卡片栏实时显示 `[轮次进度: 第 X/Y 轮接力 · 当前发言: 成员名]`；
- **全员沙箱工具平权 & 独立开关**：支持为每个角色独立设置 `[x] 允许调用沙箱工具`（开启则可读写修改文件，关闭则为纯对话构思模式）。

### 4. 中途暂停与方向手动调整 (Human-in-the-loop)
- 随时按 **`Ctrl+P`** 挂起会议；
- 无需输入可直接按回车继续，有输入则将您的指导意见注入群聊中，由下一位成员响应推进。

## ⚡ 快速启动

```bash
# 启动平台 (自动激活虚拟环境并载入配置)
run.bat
```

## ⌨️ 快捷键说明

| 快捷键 | 功能说明 |
| :--- | :--- |
| `F1` 或 `[⚙️ 设置]` | 打开 多 API 供应商 与 5 角色分工设置弹窗（按 ESC 返回） |
| `F2` 或 `[📜 历史]` | **打开历史会话管理弹窗（查看详细纪要、删除会话、清空历史）** |
| `Ctrl + P` 或 `[⏸ 暂停/调整]` | **中途暂停圆桌会议** / **直接恢复继续** |
| `Enter` 或 `[▶ 调整并继续]` | 暂停状态下输入指导并回车，注入新方向继续接力 |
| `Ctrl + C` 或 `[⏹ 彻底结束]` | 彻底终止当前任务并自动归档 |
| `F5` | 手动刷新看板与视图 |
| `Ctrl + L` | 清空实时屏幕日志 |
| `Ctrl + Q` | 退出程序 |
